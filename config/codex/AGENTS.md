# Global Codex instructions

## Git commits

コミットを依頼された場合は、次の手順に従う。

1. `git status`、`git diff`、未追跡ファイルを確認し、変更全体を把握する。
2. `git config --get commit.template` でコミットテンプレートの場所を取得し、その内容に従う。設定されていない場合は、リポジトリ内のコミット規約と直近のコミット履歴を確認する。
3. コミットメッセージは、変更内容が伝わる簡潔な表現にする。
4. 変更を目的ごとに分け、各コミットが単独で説明できる適切な粒度にする。無関係な変更を同じコミットに含めない。
5. 各コミットは、可能な範囲で単独でも検証可能かつ動作する状態にする。
6. 生成物、一時ファイル、ログ、機密情報、意図が不明な変更はコミットせず保留する。既存のユーザー変更を破棄しない。
7. コミット前に変更内容に応じた検証と `git diff --check` を実行する。
8. コミット後に `git status` を確認し、作成したコミットと保留した変更を報告する。
